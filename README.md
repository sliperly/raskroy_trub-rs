# raskroy_trub (Rust)

Программа оптимизации раскроя труб на хлысты 6000 мм для станка лазерной резки
с труборезом. Читает производственный график из Excel (выгрузка системы VOGBIT),
раскладывает заготовки по трубам и формирует для оператора готовые файлы кроя.

Это **Rust-версия** приложения. Исходная реализация на Python:
[raskroy_trub](https://github.com/sliperly/raskroy_trub). Поведение и форматы файлов
у обеих версий одинаковые; Rust-версия собирается в один `.exe` без установки
интерпретатора и зависимостей.

> **Статус:** в разработке. Полное описание поведения — в
> [ТЗ](docs/ТЗ_раскрой_трубы.md).

## Зачем это нужно

На предприятии режут листовой и трубный металл. Раскрой листа более-менее
отработан, а для трубы нет специализированной программы: оператор сам вводит
параметры реза, и на обрезках теряется много материала. Программа считает
раскрой автоматически и упрощает работу оператора.

## Как это работает

- Исходная труба 6000 мм; рабочая зона для заготовок 5745 мм (30 мм калибровка +
  215 мм зажим + 10 мм запас).
- Заготовки группируются по материалу и упаковываются в трубы: точная
  упаковка одной трубы (bounded knapsack по уникальным длинам), мультистарт в
  рамках бюджета времени и локальная чистка обрези.
- Цель: обрезь каждой трубы либо ≤ 325 мм, либо > 1250 мм.
- Для деталей с дополнительной обработкой подбираются и копируются в папку
  кроя файлы геометрии `.iges`.

Подробности алгоритма — в [ТЗ](docs/ТЗ_раскрой_трубы.md), история выбора подхода —
в [docs/ANALYSIS.md](docs/ANALYSIS.md).

## Сборка

Нужен [Rust](https://rustup.rs/) (stable, поддержка edition 2024).

```bash
git clone https://github.com/sliperly/raskroy_trub-rs.git
cd raskroy_trub-rs
cargo build --release
```

Готовый файл: `target/release/raskroy_trub.exe` (на Windows). Его можно
скопировать на любой компьютер, Rust там не нужен. Готовую сборку также можно
скачать из артефактов GitHub Actions.

## Использование

1. Положите `raskroy_trub.exe` в папку с исходными данными.
2. Рядом должен лежать один файл `График производства*.xlsx`; при
   необходимости — одна подпапка с файлами геометрии `.iges`.
3. Запустите `raskroy_trub.exe` двойным щелчком.
4. Рядом появится папка `Раскрой_<дата>`:
   - `Отчёт по раскрою трубы на <дата>.txt` — итоги по материалам и диапазонам обрези;
   - `Отчёт об ошибках на <дата>.txt` — строки, исключённые из раскроя, с причинами;
   - подпапки по материалам, в них по подпапке на каждую трубу
     (`Крой N <материал>`: текстовый файл кроя и найденные `.iges`).

Во время разработки можно запускать так:

```bash
cargo run --release
```

## Разработка

```bash
cargo fmt          # форматирование
cargo clippy       # линтер
cargo test         # тесты
```

CI (GitHub Actions) проверяет форматирование, clippy и тесты на каждый
push и pull request, а также собирает релизный `.exe`.
